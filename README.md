# My Blog Backend Application

Бэкенд веб-приложения блога, реализованный на **Java 21** с использованием **Spring Boot 3.5**.
Приложение предоставляет **REST API** для управления постами, комментариями, лайками и изображениями и интегрируется с React-frontend.

---

# 📌 Описание проекта

Приложение состоит из трёх компонентов:

* **Frontend** — React + Nginx (Docker)
* **Backend** — Spring Boot (JAR deployment, embedded server)
* **Database** — PostgreSQL или H2

---

# 🧱 Архитектура backend

Используется классическая **многоуровневая архитектура**.

---

## Controller Layer

Обрабатывает HTTP-запросы и возвращает JSON.

Примеры:

```
GET    /api/posts
POST   /api/posts
PUT    /api/posts/{id}
DELETE /api/posts/{id}
```

Ответственность:

* обработка HTTP запросов
* валидация входных данных
* возврат JSON

---

## Service Layer

Содержит бизнес-логику:

* создание постов
* редактирование
* фильтрация
* управление лайками
* управление комментариями

---

## DAO Layer

Работает с базой данных через Spring Data JDBC.

Отвечает за:

* CRUD операции
* mapping ResultSet → Model

---

## Model Layer

Основные сущности:

### Post

```
id
title
text
tags
likesCount
commentsCount
```

### Comment

```
id
text
postId
```

# 🗄 Структура базы данных

```sql
CREATE TABLE IF NOT EXISTS posts
(
    id             BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    title          TEXT NOT NULL,
    text           TEXT NOT NULL,
    likes_count    INT DEFAULT 0,
    comments_count INT DEFAULT 0
);

CREATE TABLE IF NOT EXISTS comments
(
    id      BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    text    TEXT NOT NULL,
    post_id BIGINT REFERENCES posts (id) ON DELETE CASCADE
);

CREATE TABLE IF NOT EXISTS tags
(
    id   BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name TEXT NOT NULL UNIQUE
);

CREATE TABLE IF NOT EXISTS post_tags
(
    post_id BIGINT NOT NULL,
    tag_id  BIGINT NOT NULL,
    PRIMARY KEY (post_id, tag_id),
    FOREIGN KEY (post_id) REFERENCES posts (id) ON DELETE CASCADE,
    FOREIGN KEY (tag_id) REFERENCES tags (id) ON DELETE CASCADE
);

CREATE TABLE IF NOT EXISTS images
(
    post_id BIGINT PRIMARY KEY REFERENCES posts (id) ON DELETE CASCADE,
    data    BYTEA NOT NULL
);
```

# ▶️ Запуск frontend

Перейдите в директорию frontend:

```bash
cd frontend
```

Запустите:

```bash
docker compose up -d
```

Проверьте:

```bash
docker ps
```

Frontend будет доступен:

```
http://localhost
```

---

# ▶️ Сборка backend

```bash
./gradlew build
```

После сборки JAR файл появится в:

```
build/libs/my-blog-back-app-0.0.1-SNAPSHOT.jar
```

---

# ▶️ Запуск backend

Запуск с использованием Gradle:

```bash
./gradlew bootRun
```

Или запуск JAR файла:

```bash
java -jar build/libs/my-blog-back-app-0.0.1-SNAPSHOT.jar
```

Backend будет доступен:

```
http://localhost:8080
```

# 📡 REST API

## Получение списка постов

```
GET /api/posts?search=text&pageNumber=1&pageSize=5
```

Ответ:

```json
{
  "posts": [],
  "hasPrev": false,
  "hasNext": true,
  "lastPage": 5
}
```

---

## Получение поста по ID

```
GET /api/posts/{id}
```

---

## Создание поста

```
POST /api/posts
```

```json
{
  "title": "Post title",
  "text": "Post text",
  "tags": ["spring", "java"]
}
```

---

## Обновление поста

```
PUT /api/posts/{id}
```

---

## Удаление поста

```
DELETE /api/posts/{id}
```

---

## Лайк поста

```
POST /api/posts/{id}/likes
```

---

## Изображения

```
GET /api/posts/{id}/image
PUT /api/posts/{id}/image (multipart/form-data)
```

---

## Комментарии

```
GET     /api/posts/{id}/comments
POST    /api/posts/{id}/comments
GET     /api/posts/{id}/comments/{commentId}
PUT     /api/posts/{id}/comments/{commentId}
DELETE  /api/posts/{id}/comments/{commentId}
```
